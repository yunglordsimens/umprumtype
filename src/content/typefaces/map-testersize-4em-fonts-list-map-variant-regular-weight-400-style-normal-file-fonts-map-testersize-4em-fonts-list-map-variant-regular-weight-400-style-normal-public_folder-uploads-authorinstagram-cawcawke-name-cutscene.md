description: This typeface was inspired by subtitles from the video game Devil
  May Cry (2001). What caught my attention was how the Latin letters were drawn
  by someone whose native language uses a completely different writing system,
  and the game’s graphics engine rendered the typeface in a way that deformed
  the shapes, giving it a peculiar look. My main goal was to preserve these
  letter proportions and the overall mood. Narrow capitals and monospaced traits
  shaped the typeface, giving it character while maintaining readability.
  Cutscene comes in Regular, Bold and Italic, and it can be used for both body
  text and titles.
