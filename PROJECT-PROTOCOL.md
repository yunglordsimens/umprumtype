# UMPRUM TYPE — Project Protocol (v2.0)
## Единый документ правил и целей. Обновлён 2026-05-12.

---

## ЦЕЛЬ

Сайт-архив студии типографики UMPRUM.
Показать шрифты, проекты, журнал, каталог книг (Library), витрину (Store).
Продажа без цен: контакт с автором.
Работает вечно, выглядит актуально через 10 лет.

---

## ПРИНЦИПЫ (не нарушать никогда)

1. **Главная = хаос, архивы = тишина.**  
   Главная страница — горизонтальная кинетическая лента.  
   Все остальные страницы — минимализм, списки, типографика.

2. **Шрифт показывается только тем текстом, на который отточены его глифы.**  
   Никаких рандомных панграмов, никакого showcase всех символов.  
   Specimen text = конкретный текст из `info.txt` или первая styleText.

3. **Не компрометировать шрифт.**  
   Если у шрифта нет каких-то символов — не показываем текст с этими символами.  
   Каждый шрифт показан в лучшем свете.

4. **Вне времени.**  
   Анимации: только opacity + transform (translateX, translateY).  
   Никаких модных эффектов.  
   Цвета нейтральные.  
   System fonts для UI.  
   Единственный разрешённый easing: `cubic-bezier(0.16, 1, 0.3, 1)`.

5. **Светлая/тёмная тема.**  
   Реагирует на систему (`prefers-color-scheme`).  
   На главной — оба варианта. Меню одинаковое везде.

6. **Простота CMS.**  
   Минимум полей для создания поста.  
   Для шрифтов — информация из `info.txt` (key=value).  
   Для книг — Google Sheets (NAME, AUTHOR, YEAR, TAGS, IMAGE).

7. **Mobile first.**  
   Всё должно работать на телефоне.  
   Галерея = свайп.  
   Главная на мобильном = вертикальный стэк вместо горизонтального скролла.

8. **Никаких цен в Store.**  
   Просто витрина → клик ведёт на блок «Contact author» (внутри DetailPanel или на странице поста).

## СТРУКТУРА ДАННЫХ

### Шрифты (Typefaces)
- Источник: папки в `public/fonts/` с `.otf` (или несколько вариантов) и `info.txt`.
- `info.txt`: ключ=значение (name, designer, date, aboutFont, aboutDesigner, mainText, styleText0…, mainStyleNo, tags).
- Собираются при билде функцией `getAllTypefaces()`.

### Книги (Library)
- Источник: Google Sheets (публичный CSV).
- Колонки: NAME / TITLE, AUTHOR, YEAR, TAGS, IMAGE (ссылка на Google Drive).
- Теги предопределены (18 тегов, см. ниже). Каждый тег имеет цветовую метку (`TAG_COVERS`).

### Проекты и Журнал
- Источник: markdown-файлы через Decap CMS.
- Общая структура: title, date, tags, author, body (markdown), gallery (список изображений), purchasable (boolean), contact (текст).
- Store автоматически собирает посты с `purchasable: true`.

## СТИЛЬ (ЕДИНАЯ ДИЗАЙН-СИСТЕМА)

### Фирменный стиль Library (переносится на весь проект)
- **Цвета:** нейтральные (--bg, --text, --border, --surface, --surface-alt) + акцентный оранжевый (#e05424 или аналогичный) для DetailPanel.
- **Теги:** каждый тег имеет цветной бейдж с белым текстом (берётся из таблицы `TAG_COVERS`, см. App.jsx).
- **Карточки книг:** эффект 3D-обложки (тень, градиент на корешке, блик). При наведении поднимаются на 3px.
- **Панели:** FilterPanel (левая) выезжает анимацией `max-width` + `opacity`. DetailPanel (правая) выезжает `transform: translateX(100%) → 0`, фон — оранжевый.
- **Строка поиска:** скруглённая (pill), иконка поиска слева.
- **Модальное окно:** затемнение фона, центрированное, с формой добавления книги.

### Общие правила для всех разделов
- UI-шрифт: `system-ui, -apple-system, sans-serif`.
- Цвета через CSS-переменные, никаких хардкод-цветов в компонентах.
- Активные элементы: чекбоксы в FilterPanel с галочкой, кнопки переключения с классом `is-active`.
- Галереи: горизонтальный скролл, `scroll-snap-type: x mandatory`.
- Все анимации: `cubic-bezier(0.16, 1, 0.3, 1)`, длительность 300-500ms.

### Раздел Typefaces (шрифты)
- **Аккордеон** (как на `typoumprum.cz`): список, каждый пункт раскрывается панелью с анимацией `max-height`.
- **Specimen-текст** набран живым шрифтом (динамический `@font-face`).
- **Управление:** слайдер размера, кнопки начертаний, кнопки колонок (1/2/3), сброс текста.
- **Авто-колонки:** при уменьшении кегля колонки добавляются автоматически (≤32px → 3, ≤56px → 2, >56px → 1), но ручной выбор через кнопки отключает авто-режим до следующего движения слайдера.
- **Никаких изображений.** Только типографика.

### Раздел Journal / Projects (архивы)
- **Список записей** (вертикальный), при клике открывается DetailPanel справа.
- DetailPanel: заголовок, мета-информация, горизонтальная галерея (если есть), тело поста (markdown), блок контакта (если `purchasable`).
- Фильтры (FilterPanel) слева, управляют списком.
- Используется единый компонент `ArchiveIsland.jsx` для обоих разделов.

### Раздел Store
- **Сетка карточек** (GridCard) из проектов с `purchasable: true`.
- Карточка: обложка (первое фото из галереи или цветной блок с инициалами), название, автор.
- При клике открывается DetailPanel с полным постом и выделенным блоком «Contact author».
- Фильтры и поиск аналогичны архивам.

### Раздел Library (книги)
- Три панели: фильтры слева, сетка книг в центре, DetailPanel справа.
- Карточки книг — 3D-обложки с цветом, зависящим от основного тега.
- При клике на книгу открывается DetailPanel с крупной обложкой, метаданными и тегами.
- Кнопка «Add» (в верхнем баре) открывает модальное окно для временного добавления книги (сессионно).
- Данные подгружаются через `fetch` CSV из Google Sheets при загрузке страницы.
- При пустом результате поиска/фильтров показывается сообщение «Nothing found.».

### Мобильная версия
- Навигация: burger-menu, оверлей с фоном `color-mix(in srgb, var(--surface) 98%, transparent)` и `backdrop-filter: blur(12px)`, анимация появления `translateY(-10px) → 0`.
- FilterPanel на мобильных сворачивается в кнопку-триггер.
- DetailPanel занимает 100vw.
- Главная: вертикальный стэк карточек.
- Галерея: свайп, полноэкранные фото.
- Карточки Store/Grid: одна колонка.

## ИНСТРУКЦИЯ ПО ВТОРОМУ ПРОХОДУ (для Claude Code)

1. **Library (`/library`)**
   - Взять `TAG_COVERS` и цветные бейджи тегов из оригинального `App.jsx`.
   - DetailPanel должна быть оранжевой (`#e05424`), а не нейтральной.
   - Карточки книг: добавить 3D-эффект (корешок с градиентом, падающая тень).
   - Лейаут: "UMPRUM TYPE LIBRARY" в шапке, как в оригинале.
   - Использовать шрифт system-ui для всех надписей.
   - Кнопка «Add» стилизовать как в оригинале (чёрная pill).

2. **Typefaces (`/typefaces`)**
   - Проверить, что аккордеон визуально напоминает строгий список из `umprumtype-lib` (жирные названия, тонкая линия-разделитель).
   - Убедиться, что слайдеры и кнопки используют те же стили, что и в Library (скругления, фон, ховер).

3. **Journal / Projects / Store**
   - DetailPanel должна быть оранжевой, как в Library.
   - FilterPanel — чекбоксы с анимацией, скопировать один в один из Library.
   - GridCard для Store: если нет картинки — показывать инициалы на цветном фоне (цвет зависит от тега или хэша названия, как в `GridCard.jsx`).

4. **Глобальные стили**
   - Убедиться, что все компоненты используют CSS-переменные (`--text`, `--border`, `--surface-alt` и т.д.), никаких хардкод-цветов.
   - Добавить переменные для акцентного цвета (`--accent: #e05424;`).
   - Проверить, что анимации везде используют `cubic-bezier(0.16, 1, 0.3, 1)`.

5. **Результат**
   - Все разделы визуально ощущаются как части одного сайта, а не разные проекты.
   - Library выглядит как в `umprumtype-lib`.
   - Никаких посторонних эффектов (только opacity + transform).
